# ECON-422-Github-Kristen Ngai
This is the repository to my ECON 422 project. Airline ticket prices reflect operating costs, demand, capacity constraints, competition, seasonality, and macroeconomic conditions. Jet fuel is a salient input cost, so fuel prices may contain information about future fare inflation. Yet fuel costs do not necessarily pass through immediately or one-for-one.
Research question: Does including aviation jet-fuel prices improve forecasts of U.S. airline fare inflation compared with forecasts based only on historical airline fare information? The code data has all the code used for data cleaning, analysis, and graphing. The data folder includes the csv files, and the results include figures about predictions and feature improvements.
